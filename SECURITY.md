## 🔒 1. Наши фундаментальные гарантии (Security & Privacy Guarantees)

Проект **UNBOUND** создан по принципу **Privacy & Security First**. Мы гарантируем 100% прозрачность:

| Принцип | Состояние | Описание |
| :--- | :---: | :--- |
| **Zero Telemetry** | 🛑 **ОТСУТСТВУЕТ** | В приложении нет метрик, аналитики, трекеров (Google Analytics, Yandex Metrika, Sentry и т.д.). |
| **Zero External Servers** | 🛑 **ОТСУТСТВУЕТ** | У проекта нет внешних серверов авторизации, учета пользователей или промежуточных прокси. |
| **Zero Root CA Injection** | 🛑 **ОТСУТСТВУЕТ** | Мы **НЕ устанавливаем** сторонние корневые сертификаты (Root CA) и **НЕ производим** MITM-перехват HTTPS трафика. |

## 🔬 2. Разбор технологии: Как UNBOUND обходит DPI без рисков для безопасности

В отличие от небезопасных или вирусных форков, использующих локальные MITM-прокси и установку корневых SSL-сертификатов для расшифровки пользовательских паролей:

```
[НЕБЕЗОПАСНЫЙ ПОДХОД (MITM / Левые CA)]:
Браузер ---> (Локальный MITM прокси с фальшивым CA) ---> Расшифровка трафика !!! ---> Внешний прокси

[ПОДХОД UNBOUND (Локальная L3/L4 десинхронизация)]:
Браузер ---> (Перехват пакета WinDivert / NFQUEUE / pf) ---> Фрагментация/Fake на лету ---> Заблокированный ресурс
```

- **UNBOUND не расшифровывает ваш HTTPS-трафик.**
- Ваше TLS-соединение устанавливается напрямую между вашим браузером и целевым сервером (YouTube, Discord, Telegram).
- Модифицируются только заголовки сетевых пакетов (TLS ClientHello, QUIC, HTTP Host) до их выхода в сеть.

## ⚠️ 3. Предупреждения антивирусов (WinDivert & False Positives)

На платформе Windows ядро обхода использует драйвер перехвата пакетов **WinDivert** (`WinDivert64.sys` / `WinDivert.dll`).

### Почему антивирусы могут реагировать?
1. **Категория RiskTool / PUA (Potentially Unwanted Application)**:
   - WinDivert — это легальный инструмент с цифровой подписью для низкоуровневой работы с сетевым стеком Windows.
   - Некоторые антивирусы (Kaspersky, Windows Defender, Avast) по умолчанию помечают *любые* утилиты захвата пакетов как `RiskTool.Multi.WinDivert` или `PUA`.
2. **WinDivert является компонентом с открытым исходным кодом**:
   - Драйвер WinDivert официально подрабатывается и подписывается сертификатом Microsoft. Сам по себе он не содержит вредоносного кода.

> 💡 **Рекомендация**: Если ваш антивирус блокирует WinDivert, добавьте папку с приложением в исключения антивируса или отключите детекцию PUA.

## 🗝 4. Криптографический контроль целостности бинарников (Asset Provenance)

Все бинарные файлы и драйверы (`winws2.exe`, `WinDivert.dll`, `WinDivert64.sys`, `tpws`), поставляемые с приложением, зафиксированы в манифесте провенанса **`engine/ENGINE_ASSETS.sha256`**.

Любой пользователь или разработчик может локально проверить совпадение хешей SHA256:

```bash
# Проверка целостности всех бинарных ассетов
./scripts/engine-assets.sh verify
```

В приложении в разделе **Настройки → Безопасность и Провенанс** доступна кнопка **«Проверить целостность файлов»**, выполняющая эту проверку на лету.

## 🛠 5. Как самостоятельно убедиться в безопасности UNBOUND

1. **Сборка из исходников**:
   Вы можете полностью собрать бинарники самостоятельно с помощью Go, Wails и Node.js:
   ```bash
   git clone https://github.com/bobberdolle1/unbound.git
   cd unbound
   make check
   make build
   ```
2. **Анализ сетевого трафика (Wireshark / tcpdump)**:
   Запустите Wireshark и убедитесь, что при включённом UNBOUND:
   - Нет сторонних соединений к неизвестным IP-адресам.
   - SSL/TLS сертификаты целевых сайтов выписываются их реальными центрами сертификации (DigiCert, Let's Encrypt, Google Trust Services), а не локальным центром.
