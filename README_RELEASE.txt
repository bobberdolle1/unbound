============================================================================
UNBOUND (v0.8.0+) — Инструкция по запуску и проверке релиза
============================================================================

1. БЫСТРЫЙ ЗАПУСК (GUI и CLI):
   - Распакуйте архив полностью в отдельную папку и запустите `Unbound.exe`
     (на Windows потребуется подтверждение UAC для драйвера WinDivert).
   - На главном экране вы можете:
     * запустить доказательный подбор **AutoTune vNext** (для отдельного хоста
       или мультихостового пресета ServiceGraph — YouTube / Discord);
     * выбрать готовый профиль обхода (например, `Recommended`, `Adaptive`
       или `Alternative 2`) либо открыть **Strategy Lab** для поиска новой
       стратегии с изолированным фильтром по IP цели;
     * запустить диагностику **UNBOUND Doctor** (быструю или расширенную).
   - Для консольного запуска без GUI используйте готовые `.cmd`-лаунчеры
     (`general_recommended.cmd`, `general_autotune.cmd`, `service_control.cmd`)
     либо команды `Unbound.exe --control` и `Unbound.exe --cli`.
   - Приложение работает полностью локально на уровне пакетов L3/L4, не является
     VPN/прокси и не устанавливает корневые TLS-сертификаты (Root CA).

2. ПРОВЕРКА ЦЕЛОСТНОСТИ И WINDOWS DEFENDER:
   - Перед первым запуском рекомендуется сверить контрольные суммы файлов
     с `BUNDLE_SHA256SUMS.txt` (и `SHA256SUMS.txt` на странице релиза).
   - Легитимный драйвер перехвата пакетов WinDivert (`WinDivert64.sys`) может
     помечаться антивирусами как `RiskTool.Multi.WinDivert` или `PUA` (ложное
     срабатывание на сетевую утилиту захвата пакетов).
   - Если Microsoft Defender блокирует распакованные файлы после проверки SHA256:
     1. Откройте «Безопасность Windows» -> «Защита от вирусов и угроз».
     2. Перейдите в «Управление настройками» -> «Исключения».
     3. Осознанно добавьте проверенную папку с `Unbound.exe` при необходимости.
   - Для самопроверки драйвера WinDivert на вашей системе доступен скрипт
     `verify_uac_acceptance.ps1` (запуск от имени Администратора).

3. СИСТЕМНЫЙ DNS (Secure DNS):
   - Переключатель **Secure DNS** в разделе «Настройки» при включении назначает
     публичные системные DNS-серверы Cloudflare (`1.1.1.1` / `1.0.0.1`, стандартный
     протокол UDP/TCP 53) на физические сетевые адаптеры, не затрагивая WSL/VPN.
   - Обратите внимание: эта опция настраивает классический системный DNS ОС,
     а **не** шифрованный DNS-over-HTTPS (DoH). Если ваш провайдер перехватывает
     UDP/53, рекомендуется дополнительно включить встроенный DoH непосредственно
     в настройках браузера (Chrome / Edge / Firefox).

Исходный код, документация и отчёты безопасности:
https://github.com/bobberdolle1/unbound
