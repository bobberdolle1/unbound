============================================================================
UNBOUND Refresh (v0.1.0-refresh) - Инструкция по запуску
============================================================================

1. БЫСТРЫЙ ЗАПУСК:
   - Запустите файл `unbound.exe`.
   - В открывшемся приложении нажмите кнопку "AutoTune" или выберите
     желаемый профиль обхода (например, "Recommended" или "Alternative 2").
   - Приложение работает локально и защищает ваш трафик в фоновом режиме.

2. РЕШЕНИЕ ПРОБЛЕМ С ЗАЩИТНИКОМ WINDOWS (Windows Defender):
   - WinDivert (драйвер перехвата L3/L4 пакетов) может распознаваться
     антивирусом как "Not-a-virus:RiskTool.Multi.WinDivert" или PUA.
   - Это 100% ложное срабатывание (False Positive) на компонент перехвата.
   - Если Защитник Windows блокирует запуск:
     1. Откройте: Защитник Windows -> Защита от вирусов и угроз.
     2. Перейдите в "Параметры защиты" -> "Исключения" -> "Добавить исключение".
     3. Укажите папку с распакованным `unbound.exe`.
   - При предупреждении фильтра SmartScreen ("Неизвестный издатель"):
     Нажмите "Подробнее" -> "Выполнить в любом случае".

3. БЕЗОПАСНЫЙ DNS (DoH):
   - Рекомендуется включить Secure DNS (Cloudflare DoH 1.1.1.1)
     кнопкой в настройках приложения для защиты от подмены DNS-ответов.

Подробная документация и исходный код: https://github.com/bobberdolle1/unbound
