# GitHub release notes source

Use the matching released section of `CHANGELOG.md` as the GitHub Release body. Do not use a static versioned template or autogenerated-only notes.

The current release policy publishes only:

- `unbound-v<version>-windows-amd64.zip`
- `unbound-v<version>-macos-universal.zip`
- `unbound-v<version>-macos-universal.dmg`
- `unbound-v<version>-macOS-Installer.pkg`
- `SHA256SUMS.txt`
- `RELEASE_MANIFEST.json`

Linux is experimental and has no binary release asset unless that policy is intentionally changed. Release notes must state only the bounded, evidence-backed AutoTune vNext scope and must not claim full multi-host/video YouTube coverage or QUIC/UDP vNext evidence.
