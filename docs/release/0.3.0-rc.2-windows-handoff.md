## Key UI & System Fixes in v0.3.0-rc.2
1. **Window Resizing & Scaling:**
   - Window set to horizontal desktop aspect ratio (`940 × 700 px`, min `360 × 560 px`).
   - `"disableResize": false` enabled for free mouse resizing.
2. **Platform Controls:**
   - Green traffic light button on macOS calls `windowService.toggleMaximise()`.
   - Titlebar double-click triggers window maximize/restore.
3. **Responsive Navigation:**
   - Desktop view (≥ 640px) shows full non-clipped labels: `[Главная] [Профили & LUA] [Списки обхода] [Настройки]`.
   - Compact view (< 640px) uses clean short labels: `[Главная] [Профили] [Списки] [Настройки]` without ellipsis.
