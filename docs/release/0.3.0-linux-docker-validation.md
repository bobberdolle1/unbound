## 7. What Docker Cannot Confirm (Explicitly NOT TESTED)
The Docker build validation confirms compilation, dynamic library linking, asset embedded integrity, and headless GUI startup. However, Docker Desktop **cannot** confirm:
* Real Linux desktop display execution (GNOME 46+, KDE Plasma 6+, XFCE).
* Native GNOME / KDE titlebar rendering and window dragging.
* Wayland native display compositor protocol integration.
* Desktop notification area / System Tray integration (AppIndicator / GNOME extensions).
* Root / Polkit authorization dialog UI flow.
* Systemd service installation and OS autostart service persistence.
* Real host `nftables` / `iptables` rules and `NFQUEUE` desync on a physical Linux kernel.
* Real user network traffic desync bypass on a Linux desktop.
* Rule cleanup after OS system crash or reboot.
* Distribution matrix (`Debian 12`, `Arch Linux`, `Fedora 40`, `openSUSE`).
* `linux/arm64` architecture.
