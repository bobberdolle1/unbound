## What Was Refactored in v0.3.0-rc.1

1. **Precision Monochrome Design System:**
   - Pure monochrome palette (`#08090b` canvas, `#141416` panels, `#1a1a1a` surfaces, `#ffffff` primary action buttons on dark, `#141416` on light).
   - Removed all blue, cyan, sky blue, and electric blue accents.
   - Semantic status indicators only (Emerald connected, Amber connecting, Red error, Slate disconnected).
   - Tactical depth using 1px border highlights (`rgba(255,255,255,0.10)`), clean typography (`SF Pro` / `Inter`), no unnecessary glassmorphism or neon glows.

2. **Themes Available:**
   - **`Monolith`** (Primary Dark): Pure monochrome obsidian.
   - **`Paper`** (Warm Studio Light): Warm canvas (`#f5f4f0`) with solid dark controls.
   - **`Graphite`** (Steel Dark): Compact steel-toned theme with 6px radii and metal inner highlights.
   - *(Note: Arcade Paper has been deferred to a future phase and is NOT in production)*.

3. **Platform-Aware Custom Titlebar:**
   - Window controls dynamically adjust per platform:
     - `darwin`: macOS traffic lights on the left;
     - `windows`: Windows 11 Fluent controls (`─`, `✕`) on the right;
     - `linux`: Neutral header layout.
   - Connected directly to Wails runtime APIs (`WindowMinimise`, `HideWindowToTray`, `QuitApp`).

4. **Architecture & Decomposition:**
   - `App.tsx` decomposed into dedicated components: `PlatformTitlebar`, `AppNavigation`, `MainControlView`, `ProfilesView`, `BypassListsView`, `SettingsView`, `ModalHost`, `LogJournalDrawer`, `ConnectionStatus`.
   - Domain hooks introduced: `usePlatform`, `useEngineController`, `useEngineEvents`, `usePingPolling`, `useLogJournal`, `useHostlists`, `useLuaEditor`, `useKeyboardShortcuts`.
   - Typed services layer: `services/backend.ts` and `services/window.ts`.

5. **Legacy Cleanup & Assets:**
   - Completely removed `DoodleSelect`, `DoodleCheckbox`, `Sketchy*` compatibility aliases.
   - Replaced with `UISelect`, `UICheckbox`, `UISpinner`, `UIStar`, etc.
   - Cleaned up obsolete font assets (`Comic Neue`, `Permanent Marker`, `VT323`) — bundle reduced by 34%.
   - Single Source of Truth for branding: `build/logo.svg` (U-Break monogram mark), synced via `make sync-logo` (`scripts/generate_all_icons.py`).
   - Windows ICO generated as multi-resolution ICO (16x16 ... 256x256, 17.5 KB).

6. **Automated Testing:**
   - 31 Vitest frontend tests covering components, hooks lifecycle, navigation, modals, and status transitions.
   - Full Go backend unit and integration test suite passing across all packages (`go test ./...`).

## Local Verification Commands (Run on Windows 11)

```cmd
:: 1. Checkout repository and branch
git clone https://github.com/bobberdolle1/unbound.git
cd unbound
git checkout release/0.3.0-rc.1

:: 2. Verify HEAD commit matches 14bd808
git rev-parse HEAD

:: 3. Frontend checks
cd frontend
npm ci
npx tsc --noEmit
npm test
npm run build
cd ..

:: 4. Backend tests
go test ./...

:: 5. Wails doctor & Windows build
wails doctor
wails build -clean -ldflags "-X unbound/engine.Version=0.3.0-rc.1"
```
