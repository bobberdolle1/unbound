# 🕵️ Независимый отчет по безопасности и аудиту UNBOUND

В данном документе представлен технический отчёт по результатам проверки кода, зависимости и сетевого поведения приложения **UNBOUND Refresh (`v0.1.0-refresh`)**.

---

## 1. Сравнительный анализ архитектуры безопасности

| Критерий безопасности | UNBOUND Refresh | Вредоносные / Непроверенные форки |
| :--- | :--- | :--- |
| **Принцип работы** | Локальная десинхронизация L3/L4 TCP/UDP пакетов | Навязываемый локальный HTTP/SOCKS прокси |
| **Управление SSL/TLS** | **Прямой TLS-Handshake** с целевым сервером | **MITM-перехват** с генерацией фейкового корневого CA |
| **Конфиденциальность данных** | Пароли и куки не читаются и не модифицируются | Трафик расшифровывается в открытом виде на прокси |
| **Сетевые правила** | Временная цепочка `nftables` / `pf` anchor / `WinDivert` | Модификация системных DNS и подмена файла `hosts` |
| **Исходный код** | 100% Открытый код на Go/TypeScript/React | Закрытые DLL-инъекции или обфусцированные скрипты |
| **Телеметрия** | 0 внешних вызовов, 0 аналитических серверов | Сбор IP, списков посещаемых сайтов и UID устройств |

---

## 2. Анализ зависимостей и бинарных компонентов

1. **Go-модули (`go.mod`)**:
   - `github.com/wailsapp/wails/v2`: официальный open-source фреймворк для нативных десктопных GUI.
   - Внешние зависимости Go ограничены стандартной библиотекой Go и официальным Wails рантаймом.
2. **Фронтенд-зависимости (`frontend/package.json`)**:
   - `react`, `react-dom`, `tailwindcss`, `vite`, `typescript`.
   - Отсутствуют аналитические библиотеки (Google Analytics, Mixpanel, Sentry, PostHog, Segment).
3. **Шрифты и графические ресурсы**:
   - Все шрифты (Inter, Comic Neue, Permanent Marker, VT323) **забандлены локально** в `frontend/src/fonts/`.
   - Приложение **не осуществляет внешней загрузки** шрифтов с `fonts.googleapis.com` или CDN во время работы.

---

## 3. Манифест целостности ассетов (`ENGINE_ASSETS.sha256`)

Все поставляемые бинарные модули (`winws2.exe`, `WinDivert.dll`, `WinDivert64.sys`, `tpws`, Lua-скрипты и фальшивые сигнатуры `zero_1024.bin`, `tls_clienthello_*.bin`) покрыты криптографическими контрольными суммами SHA256.

Система сборки и проверки `scripts/engine-assets.sh verify` гарантирует:
- Ни один файл не может быть подменён без обнаружения.
- Ни один сторонний бинарник не может быть внедрен мимо манифеста.

---

## 4. Пошаговое руководство по самостоятельной верификации

Убедиться в полной безопасности UNBOUND можно 3 независимыми способами:

### Способ А. Проверка сетевого трафика через Wireshark
1. Откройте **Wireshark** и начните захват пакетов на вашем сетевом интерфейсе.
2. Запустите UNBOUND и включите обход DPI.
3. Откройте YouTube или Discord.
4. Проверьте фильтр `ip.dst`: трафик идет **напрямую к IP-адресам Google / Discord**, минуя какие-либо сторонние промежуточные IP.
5. Проверьте TLS Сертификат сайта в браузере: вы увидите оригинальный сертификат Google Trust Services / DigiCert.

### Способ Б. Локальная сборка из исходников
```bash
git clone https://github.com/bobberdolle1/unbound.git
cd unbound
make check
make build
```

### Способ В. Проверка целостности ассетов
```bash
./scripts/check.sh assets
```
Показывает статус верификации всех 130 бинарных файлов.
