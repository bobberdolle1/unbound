# Заметки о выпуске UNBOUND Refresh `v0.1.0-refresh`

## 🔄 Перезагрузка проекта

- **Переход на чистую версию `v0.1.0-refresh`**: Отказ от выпуска сырых релизов до достижения полной отполированности ядра.
- **Фокус на 3 основных настольных платформах**: Поддержка сфокусирована исключительно на **Windows 10/11**, **Linux** и **macOS**.
- **Удаление сырых и неработающих платформирований**: Из дерева репозитория удалены мобильные, браузерные и ТВ модули (Android VpnService/JNI, Magisk module, Steam Deck plugin, Web Extension, OpenWrt, LG WebOS, tvOS).
- **Архивация наследия (v2.x)**: Весь старый код v2.5.0 со сторонними модулями сохранён в отдельной ветке `legacy/v2.x`.
- **Очистка CI/CD и автоматизаций**: Удалены скрипты деплоя в GitHub Pages (`pages.yml`), обновлены CI проверки (`ci.yml`, `release.yml`) и локальный тестовый комбайн `scripts/check.sh`.
