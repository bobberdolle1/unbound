# Заметки о выпуске UNBOUND v2.5.0

## МАЖОРНЫЕ ВОЗМОЖНОСТИ (Windows-версия)

- **Обновление ядра до Zapret 2 v1.0.2** — Переход на актуальный бинарный файл `winws2.exe`, библиотеки `WinDivert.dll`/`WinDivert64.sys` и набор Lua-скриптов для повышенной стабильности и обхода новых сигнатур DPI.
- **Автоматический запрос прав UAC** — В манифест добавлен запрос прав администратора, что исключает сбои при инициализации сетевого драйвера WinDivert.
- **Тихий автозапуск в трей** — Поддержка бесшумного автозапуска приложения с флагом `-tray` при старте Windows через планировщик.
- **Встроенный Редактор Списков Обхода** — Возможность безопасного добавления и редактирования доменов в списках `youtube.txt`, `discord.txt`, `other.txt`, `ipset-exclude.txt` прямо из настроек UI.
- **Безопасный DNS (DoH)** — Включение шифрования DNS-запросов через Cloudflare DNS (`1.1.1.1` и `1.0.0.1`) для предотвращения подмены IP на уровне провайдера (DNS Spoofing).
- **Экспорт журналов событий** — Удобная кнопка для сохранения истории логов в текстовый файл с нативным диалогом Windows.
- **Визуальный Конструктор Lua-Стратегий** — Простой интерфейс для настройки десинхронизации (сплита, фейковых пакетов, TTL и метода обмана DPI) без ручного написания Lua-кода.
- **Интерактивный график пинга** — Анимированная SVG-линия задержки в реальном времени до заблокированных ресурсов.
- **Аура статуса и 12 Аура-тем** — Эффекты неонового свечения и 6 новых премиальных тем оформления (iOS 6 Classic, Windows XP, macOS Spatial, Windows 8 Metro, iOS 26 Hologram, Interstellar Gravity) из промо-сайта.

## Исправления и улучшения

- Полный рефакторинг и исправление тестового фреймворка (`go test ./...`) для прохождения всех тестов как под Администратором, так и в обычной консоли.
- Добавлен параметр `InsecureSkipVerify: true` для прохождения оптимизации при сбоях синхронизации времени и тестирования на mock-серверах.
- Оптимизирован сброс и очистка службы и драйвера WinDivert при завершении конфликтующих процессов.
- Автоматическая очистка кэша Discord и оптимизация TCP Timestamps работают стабильно.
