# 🖥 Поддерживаемые платформы UNBOUND Refresh `v0.1.5`

В версии **UNBOUND Refresh** разработка и поддержка сфокусированы исключительно на 3 основных настольных платформах.

| Платформа | Драйвер / Перехват | Формат | Механизм |
|-----------|--------------------|--------|----------|
| 🪟 **Windows** | `WinDivert` (`winws2`) | Wails GUI + CLI | Перехват и десинхронизация сетевых пакетов на уровне ядра Windows |
| 🐧 **Linux** | `NFQUEUE` (`nfqws`) | CLI + Wails GUI | Перехват через `nftables` / `iptables` и обработка пакетов в NFQUEUE |
| 🍎 **macOS** | `pf` divert socket (`nfqws`) | Wails GUI (Universal) + CLI | Перехват через якорные правила `pf` (`com.unbound.zapret`) |

---

## 🪟 Windows

**Движок:** Wails (Go + WebView2) + WinDivert + Zapret 2 (`winws2.exe`).

### Особенности
- Драйвер `WinDivert` обеспечивает прозрачный перехват L3/L4 пакетов на уровне ядра без настройки прокси.
- UAC-автоэлевация для затребования прав администратора при запуске.
- Бесшумный автозапуск в системный трей через Windows Task Scheduler.
- Встроенный визуальный конструктор LUA-стратегий и редактор списков (`youtube.txt`, `discord.txt`, `ipset-exclude.txt`).
- Защита DNS через Cloudflare DoH (`1.1.1.1` / `1.0.0.1`).

---

## 🐧 Linux

**Движок:** Go CLI/GUI + `nftables` / `iptables` + `nfqws`.

### Особенности
- Интеграция с подсистемой ядра Linux `netfilter` через сокеты `NFQUEUE`.
- Поддержка нативной подсистемы `nftables` (таблица `inet unbound`) с автоматическим фолбэком на `iptables`.
- Гарантированный возврат сетевых правил при остановке или завершении процесса (`Flush` правил по точному совпадению).
- Поддержка архитектур `amd64` и `arm64`.

---

## 🍎 macOS

**Движок:** Wails (Go + WebKit) + `pf` divert socket + `nfqws`.

### Особенности
- Прямая десинхронизация пакетов через `pf` divert socket.
- Кастомные правила загружаются в изолированный `pf`-якорь `com.unbound.zapret`, не затрагивая основной фаервол пользователя.
- Безопасная очистка правил файрвола при завершении приложения.
- Поддержка Apple Silicon (`arm64`) и Intel (`x86_64`) через Universal App Bundle.

---

## 🗂 Примечание о legacy-платформах

Все прочие экспериментальные целевые платформы (Android APK, Magisk module, OpenWrt, Steam Deck Decky plugin, Web Extension, LG WebOS, iOS/tvOS) удалены из основной ветки разработок и заархивированы в ветке `legacy/v2.x`.
